GAMEFOWL FINANCE TRACKER

This is a responsive, offline-capable web app in one HTML file.

To test:
1. Open index.html in a browser on a computer.
2. For iPhone/Android, put index.html on a web host (GitHub Pages, Netlify, Cloudflare Pages, or similar) and open the resulting HTTPS link.
3. Add the page to your Home Screen for app-like access.

Important:
- Data is stored in the browser's local storage.
- Use Backup > Export Backup before changing phones or browsers.
- Import the JSON backup on the new device.
- Initial Expense on the dashboard automatically includes each trio's breeding capital + housing/cage capital + any expenses marked Initial / Capital.
